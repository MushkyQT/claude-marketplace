Scopekeeper Pane Guide

The pane opened by /scope shows what is installed globally in Claude Code, how much you use each piece and where, and the per-project kits that replace them. This guide walks through each view and every key.

Moving around

The pane sits beside the conversation when the terminal is wide enough (fullscreen layout, 110 columns or more) and above the prompt otherwise. It opens with the keyboard, the cursor on the first row.

Tab ↑ ↓

Move the cursor, one visible line at a time. Moving never opens or closes anything, so the rows stay where they are.

Letter keys

Every action shows its key in front of it (k: Keep global) and works while the pane has the keyboard.

Enter

Press what the cursor is on: a global or kit row opens right under it, its actions first and its details below them (the open row is marked ›; Enter on it again closes it), a project row of a kit toggles it there, a button runs.

Esc

Hand the keyboard back to the prompt. The pane stays open and keeps updating.

Back into the pane

Click it, or press Ctrl+X then Tab. Running /scope again also brings it back with the keyboard.

Close

Use the pane's close mark. Nothing is lost: the data lives in the plugin, and /scope reopens it.

Header

Always at the top, on both tabs: what was found, what is waiting on you, and the keys. The local pane puts its keys in the same row under its header; both end with what Enter does on the row under the cursor.

All optional lines shown at once. Normally you see the first three.

usage since Jun 9

The oldest use scopekeeper has on record. Claude Code deletes old transcripts, so a count of 0 means unused since that date, not unused ever.

▸ waiting line

unsorted: globals you haven't decided about. to adopt: globals a kit covers that are still installed everywhere. used but off: projects where you used a kit's tools but it is off. stale: projects where a kit sat unused past the stale limit.

When nothing waits it turns green: ✓ Nothing waiting on you. The status line repeats the unsorted and to-adopt counts.

g Globals · i Kits

Switch tabs. The current tab is bold and underlined.

r Rescan

Re-read what is installed and where each kit is on. The yellow line shows while it runs. The pane also rescans by itself after every action.

s Set up shell

Only shown when your shell doesn't load the cc-* functions yet. Asks once, then adds one line to ~/.zshrc (zsh) or to ~/.bashrc and the bash login file.

t Let Claude triage

Only shown when something is unsorted. Claude works out how each unsorted item was installed, groups what belongs together, asks you about each group, and saves kits or keep-globals. Claude never installs or removes anything here; you do that from the pane.

a Back to local

Closes this pane and opens the local one (Scope · Local). Only one of the two is open at a time.

! red lines

Something to fix, such as the shell not loading cc-*, a shell like fish that can't, or no python3 to read past transcripts with.

The columns

kind

plugin, skill, agent or mcp. Dropped, with proj, when the pane is narrow.

calls

Recorded uses: skill runs, MCP tool calls, agent runs and slash commands. A plugin counts everything it brings (its skills, its MCP server). … while past transcripts are still being read.

last

Time since the last use: minutes, hours, days, months, or — for none on record.

proj

How many projects used it. A project is a repo's root folder (worktrees count as their main repo), or the folder itself outside git. Your home folder never counts.

status

new not decided yet: either keep it global or turn it into a kit.

→ blender the kit blender covers it, but it is still installed globally. Adopt finishes the move.

keep you chose to keep it global. These sit under Kept global; press Enter on that row to show them.

The open item

Enter on an item opens its details under it, and closes them again: the install path, the projects that used it (up to 5, most used first), what its status means, and its actions. A key acts on the open item. The actions depend on its status:

StatusActionKeyWhat it does
new or keepMake a kitmStarts a triage with Claude for this one item.
newKeep globalkMarks it as intentionally global. It stops counting as unsorted.
keepUnkeepuPuts it back to unsorted.
→ kitAdopt <kit>oSame as Adopt on the Kits tab (below).
anyRemovexTakes it out of the global setup after asking, saying how much it was used and since when. Plugins and MCP servers are uninstalled; skill and agent folders are moved to ~/.claude/scopekeeper/backups/, never deleted. Not offered until past transcripts are read, so a 0 that only means "not counted yet" can't mislead you.

The dim lines under Recent at the bottom are the last three things the pane did; the newest is shown whole. A question you cancelled leaves no line, as nothing changed.

A kit row

kit and what

The kit and its description. The description is dropped when the pane is narrow.

on in

How many projects have every part of the kit set up; — for none.

to do

adopt some part is still installed globally. Adopt removes it once the projects have it.

turn on 2 projects where you used these tools but the kit is off. Adopt, or Enter on each project, turns it on there.

prune 1 projects where it went unused past the stale limit. Prune takes it out of them.

The open kit

Enter on a kit opens its details under it, and closes them again: every part it installs (a command it runs is shown in full), its two shell commands, what is left to do, one row per project (newest use first), then its actions. A key acts on the open kit.

Confirmations

Anything that installs, uninstalls, moves files or edits a shell file asks first, in Claude's question dialog.

  1. The question says exactly what will happen: the project paths, the installs it would remove, and what enabling a kit installs and runs.
  2. Pick an answer with the arrow keys or its number, then Enter.
  3. Esc on the dialog counts as cancel. Nothing changes.
  4. The result appears as a short notice, and in the pane: under Recent in the advanced pane, as Last: in the local one. Cancelling only shows the notice.

Commands

Everything the pane does is also a command, handy at narrow widths or when you know what you want.

CommandDoes
/scopeOpens the pane (or brings it back with the keyboard).
/scope auditPrints the overview as text: what is waiting on you, every global with its usage, every kit with where it's on, off or stale.
/scope triageSame as the Triage key.
/scope adopt designAdopt a kit by name.
/scope enable designTurn a kit on in this session's project.
/scope off designTurn a kit off in this session's project.
/scope backfillRe-read usage from your transcripts.
cc-designFrom a shell in a project folder: turn the kit on there. cc-design-off turns it off.
